# 🤝 Contributing to *Linux for Humans*

First off, **thank you** for considering contributing to this project! Whether it’s a typo fix, a new guide, or a suggestion, your help is welcome.

---

## **📌 How to Contribute**

### **1. Report a Bug or Suggest an Improvement**
- **Open an Issue**: If you find a mistake, have a suggestion, or want to request a new feature (e.g., a new quiz or guide), [open an issue](https://github.com/CtrlAltBeard/linux-for-humans/issues) and describe it.
- **Be clear**: Include details like:
  - What you found (e.g., "The quiz result for Mostly C’s links to a broken URL").
  - What you expected (e.g., "The link should point to Arch Linux’s official site").
  - Screenshots (if helpful).

### **2. Fix a Typo or Update Content**
- **Fork the repo**: Click the **Fork** button at the top-right of the repo page.
- **Make your changes**: Edit the file(s) in your fork.
- **Submit a Pull Request (PR)**:
  1. Go to your fork on GitHub.
  2. Click **Pull requests** > **New pull request**.
  3. Select the original repo (`CtrlAltBeard/linux-for-humans`) as the base and your fork as the compare.
  4. Add a **clear title and description** (e.g., "Fixed typo in distro-matchmaker.md").
  5. Click **Create pull request**.

### **3. Add New Content**
Want to add a new guide, quiz, or resource?
- **Open an Issue first**: Discuss your idea with me to make sure it fits the project’s goals.
- **Follow the style**: Use the same tone (beginner-friendly, humorous, and clear) and formatting as the existing content.
- **Add it to the README**: If your addition is significant, update the `README.md` to link to it.

### **4. Improve the Repo Itself**
- **Better `.gitignore`?** Suggest additions.
- **New LICENSE?** Let’s discuss.
- **Automation?** Want to add GitHub Actions for spell-checking or link validation? Open an issue!

---

## **🎯 Contribution Guidelines**
- **Be kind**: This is a beginner-friendly project. Avoid jargon or condescension.
- **Keep it simple**: Assume the reader knows *nothing* about Linux.
- **Test your changes**: If you’re adding a guide, try the steps yourself to make sure they work.
- **Respect the LICENSE**: All contributions must be compatible with the [MIT License](LICENSE).

---
## **🙌 Recognition**
All contributors will be **credited** in the `README.md` (if you want). Just let me know your GitHub username or how you’d like to be acknowledged!
